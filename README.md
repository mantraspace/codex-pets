# Codex Pets

A collection of custom pets for Codex.

Codex is OpenAI's AI coding agent for software development.
[Learn more about Codex](https://openai.com/codex/).

For information about creating and using custom pets, see the
[official Pets documentation](https://learn.chatgpt.com/docs/pets).

## Pets

- **Micro** — A retro toy microcomputer with a beige case, green screen eyes, keyboard, and waving cable.
